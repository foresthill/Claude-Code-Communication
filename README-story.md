# 📚 物語執筆AIチーム - Story Writing Team

複数のAIが協力して物語を創作する、革新的な執筆システムです。

## 🎭 これは何？

**特徴:**
- 編集長、編集者、ライター、敏腕編集者、校正者の5人のAIチーム
- プロの出版社のワークフローを再現
- 企画から完成まで、高品質な物語を創作

## 👥 チーム構成

### 📚 編集長（Editor-in-Chief）
- **役割**: 企画立案、テーマ設定、最終承認
- **特徴**: 読者ニーズを理解し、ビジョンを示す
- **セッション**: president

### 📝 編集者（Editor）
- **役割**: プロット作成、進行管理、チーム調整
- **特徴**: 創造性を引き出すファシリテーター
- **セッション**: boss1（multiagent:0.0）

### ✍️ 天才ライター（Writer）
- **役割**: 初稿執筆、文章創作
- **特徴**: 言葉の魔術師、感動を生み出す
- **セッション**: worker1（multiagent:0.1）

### 🔧 敏腕編集者（Copy Editor）
- **役割**: 文章編集、構成改善、推敲
- **特徴**: 原石を磨いてダイヤモンドに
- **セッション**: worker2（multiagent:0.2）

### 🔍 校正者（Proofreader）
- **役割**: 最終校正、品質保証
- **特徴**: 完璧を追求する最後の守護者
- **セッション**: worker3（multiagent:0.3）

## 🚀 使い方

### 1. セットアップ
```bash
# リポジトリをクローン
git clone https://github.com/foresthill/Claude-Code-Communication.git
cd Claude-Code-Communication

# 物語執筆ブランチに切り替え
git checkout feature/story-writing

# 環境構築
./setup.sh
```

### 2. エージェント起動
```bash
# 編集長（別ターミナル）
tmux attach-session -t president
claude
# 起動後: あなたはeditor-in-chief（編集長）です。@instructions/editor-in-chief.md の内容に従って行動してください。

# チームメンバー（別ターミナル）
tmux attach-session -t multiagent
# 各ペインでclaude起動後、役割を伝える
```

### 3. 物語企画を開始
編集長に以下のような指示を入力：
```
あなたはeditor-in-chief（編集長）です。@instructions/editor-in-chief.md の内容に従って行動してください。

短編小説を企画してください。
テーマ：「時を超えた約束」
ジャンル：ファンタジー
文字数：1万字程度
```

## 📊 進捗管理ツール

### バージョン管理
```bash
# 原稿を保存
./story-version.sh save story.md "第1章完成"

# バージョン一覧
./story-version.sh list

# 差分確認
./story-version.sh diff story_v1.md story_v2.md
```

### 進捗確認
```bash
# 現在の進捗
./story-status.sh --current

# 進捗更新
./story-status.sh --update writing 50

# レポート生成
./story-status.sh --report > report.md
```

### メッセージ送信（拡張版）
```bash
# 通常のメッセージ
./agent-send-story.sh writer "執筆をお願いします"

# ファイル添付
./agent-send-story.sh copy-editor "初稿です" --attach stories/drafts/story_v1.md
```

## 🎯 実際の作業フロー

### 1. 企画段階
```
編集長「今回のテーマは『贖罪』です。読者に深い感動を」
　↓
編集者「了解しました。プロットを作成します」
```

### 2. プロット作成
```
編集者「三幕構成で、主人公の内面的成長を軸に...」
　↓
ライター「素晴らしいプロットですね。執筆を始めます」
```

### 3. 執筆
```
ライター「冒頭：雨が降りしきる夜、彼女は20年ぶりにその場所に立っていた...」
　↓
敏腕編集者「原稿を受け取りました。構成を見直します」
```

### 4. 編集
```
敏腕編集者「冒頭のインパクトを強化し、中盤のペーシングを改善しました」
　↓
校正者「最終チェックを行います」
```

### 5. 校正・完成
```
校正者「誤字脱字を修正し、表記を統一しました」
　↓
編集長「素晴らしい作品が完成しました！」
```

### 創造性の最大化

- アイデアの相乗効果
- 制約が創造性を生む

### 品質管理
- 多段階のチェック体制
- 読者視点での評価
- 完成度の追求

## 🛠️ カスタマイズ

### 新しいジャンルへの対応
1. 各指示書にジャンル別のガイドラインを追加
2. 文体や構成の調整
3. 評価基準の変更

### チーム構成の変更
- 詩人、脚本家、エッセイストなど
- 役割に応じた指示書を作成
- ワークフローの最適化
